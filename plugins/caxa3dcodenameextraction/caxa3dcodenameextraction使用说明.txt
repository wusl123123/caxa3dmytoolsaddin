带图改名及图号分离  使用说明
============================================================

一、随插件附带的 2027 配置文件（需用户自行加载一次）
------------------------------------------------------------
编译输出目录（bin\x64\Release\net48）下的 caxa3d2027关键设置\ 文件夹内附
四个配置文件与关键设置截图，仅供人工导入/参考，安装脚本不会把它们复制进 CAXA 安装目录：

  1. caxa3d配置2027.ucx ...... CAXA 3D 2027 选项配置
  2. caxa3d属性模板.xml ...... 自定义属性模板（含 SC图号 / SC名称 / SC规格 / SC材料 等字段）
  3. caxabom.xml ............. BOM 表列配置
  4. caxa2d配置.xml .......... CAXA 2D 图纸环境配置
  · 关键设置1.PNG / 关键设置2.PNG / 特征树显示.PNG —— 关键选项设置截图，供对照

加载方式（任选其一，按本机 CAXA 版本界面为准）：
  · 选项配置：CAXA 3D → 工具 → 选项 → 配置管理/导入，选择 caxa3d配置2027.ucx 导入。
  · 属性模板：CAXA 3D → 工具 → 属性模板（自定义属性模板）→ 导入，选择 caxa3d属性模板.xml。
  · BOM 配置：CAXA 3D → 工具 → BOM 表设置/配置 → 导入，选择 caxabom.xml。
  · 2D 配置：图纸环境（CAXADraft）→ 工具/选项 → 配置导入，选择 caxa2d配置.xml。

说明：
  · 这四个文件不是插件运行必需，但强烈建议加载——属性模板里已预置 SC图号/SC名称/SC规格/SC材料
    四类属性，图号分离就是往这些属性里回填；没有这些属性时，属性回填会新建同名属性，
    但设计树/BOM 的显示列不一致，看起来像“没写进去”。
  · 配置文件属于人工配置，插件不会自动覆盖或删除，卸载插件也不会移除它们。

二、运行前提
------------------------------------------------------------
  1. CAXA 3D 2027 及以上，选项里开启“同名 ics/exb 联动”（本地保存同名零件与图纸）。
  2. 旧工程（改名前 ics/exb 不同名）需先手工转存一次，让两者同名。
  3. 本插件已并入集合体：功能区只有「我的工具箱」一个按钮，
     点它 → 在「1. 常用插件」列点「带图改名及图号分离」打开本窗口。
  4. 插件需注册 CRX（图纸环境命令模块）：点窗口内「注册CRX」后重启 CAXA 生效。
     缺 CRX 的典型现象是：改名能成，但图纸一直不关、等到超时。

三、界面：从上到下的五行与操作步骤
------------------------------------------------------------
窗口从上到下五行，顺序就是使用顺序：

  第 1 行（工具行）  窗口前置、图号分离规则、使用说明、刷新连接、注册CRX、
                     卸载CRX、保存日志、清理日志
  第 2 行            图纸环境预热（按钮底色即状态灯：绿=已预热，黄绿=预热过但图纸已关，红=未预热）
  第 3 行            原零件名 / 新零件名（右侧各带一句状态：存在工程图、零件名已存在…）
  第 4 行            分离规则下拉 + 自动图号分离
  第 5 行            带图独立、重命名（蓝底主按钮）、右侧实时状态字（“就绪”等）
  第 6 行            手动图号分离、钣金件设计环境设默认、工程图标题栏设默认、停止（4 列等宽）
  第 7 行            替换零部件、钣金件尺寸填写、更新工程图链接文件、零部件重新生成（4 列等宽）
  最下面             运行日志（等宽字体，可滚动、可保存为 txt）

长流程（带图独立 / 重命名 / 替换 / 更新链接 / 钣金 / 标题栏 / 尺寸填写）同一时刻只允许一条：
跑起来后其它流程按钮禁用，「停止」可用。停止**不会**强行保存、也不会关图。

1. 选区与两个名称框
   - 在 3D 环境中选中一个零部件（本窗口可先点「窗口前置」锁定在最上层）。
   - 原零件名右侧显示“存在工程图 / 不存在工程图”。
   - 显示“零部件(虚拟)”表示虚拟件：虚拟件不能重命名，要先另存为外部 ics。
   - 新零件名默认填入原零件名；若这个件的外链文件名与零件名已经不一致
     （刚做过「带图独立」或「替换零部件」），自动填的是**外链文件名**，
     状态栏会提示“外链已是 X.ics，元素名还是 Y，点「重命名」即可对齐”。
   - 右侧显示“零件不存在”= 绿色通路；红字“零件名已存在”时按钮不可点，请换名。

2. 分离规则下拉 + 「自动图号分离」开关
   - 下拉项来自 caxa3dcodenameextraction图号分离规则.txt（与插件同目录）。
   - 开关默认开启（蓝色）：重命名时回填 SC图号/SC名称/…，并校验段数。
   - 点一下变白即关闭：只改名，不回填属性、不校验段数；再点一下恢复。

3. 「重命名」
   ① 回填图号分离属性（开关关闭时跳过）
   ② 回填零件名（set_Name）→ 立刻回读比对，不一致补一次 Update 再回读
   ③ 保存 ics（CAXA 2027 自动把本地文件名改成新零件名）
   ④ 打开同名 exb，自动代点“是否更新外链文件名 → 是”
   ⑤ 保存并关闭工程图（只认标题含该文件名、且 class 是图纸视图的窗口）
   ⑥ 焦点回到设计环境
   没有同名 exb 时只做 ①②③⑥，不打开图纸。

   ★ 带约束的外链件改名会弹 CAXA 自己的「你是否要修改和保存这个外链文件的文件名?」：
     新名 ics 已在盘上时，插件对这一张点**取消**（点“是”会让宿主按旧链接回写、整笔回滚）。
     改名后插件会按名回读；回读不符时界面写「改名没生效」而不会写“完成”。
   ★ 不再自动执行“重新生成零部件”（装配体下太慢）。设计树仍显示旧名时，
     点 ④ 区的「零部件重新生成」，或在设计树里手工点一次“重新生成”。

4. 「带图独立」——一键串起“替换 → 改名 → 更新图纸链接”三步
   前置：必须是外链件，且“外链文件名 = 零件名”（如 设计环境.ics - 零件A(外链)，零件A.ics 同名）；
   「新零件名」填 零件B。任何一步校验不过直接弹提示，不做修改。
   ① 把 零件A.ics 与同名 零件A.exb 复制到设计环境 ics 所在文件夹，改名 零件B.ics / 零件B.exb
      （两个目标先全量校验，任一已存在即中止，绝不覆盖）
   ② 自动投递并代点 CAXA 原生「替换零件/装配」面板（含两张业务框：先选未展开项再点确定），
      把这一个元素的外链指向 零件B.ics
   ③ 遍历设计树验证确有元素外链指向 零件B.ics（不依赖你当前选中了谁），
      没验证上就中止并说明「复制出的新文件仍在文件夹内」
   ④ 回填 SC 属性 → 元素名改成 零件B → 保存设计环境，修成“零件B.ics - 零件B”
   ⑤ 打开 零件B.exb → 派发「改变链接文件」把图纸外链指到 零件B.ics → 保存并关闭
      目标文件夹内没有 零件B.exb 时这一步自动跳过
   其它仍指向 零件A.ics 的同链接件不受影响。钣金件同样可走（替换后仍保持钣金零件类型）。
   已知边界：复制出的 零件B.exb 内部 3D 引用仍指向 零件A.ics（插件不改写 exb 内部数据）。

5. 「替换零部件」（只做替换这一步：不改名、不分离、不保存）
   前置与「带图独立」相同。流程：复制 零件A.ics → 零件B.ics（已存在即中止）→
   把选中件补进 CAXA 活选择集 → 投递 WM_COMMAND 53851 叫出「替换零件/装配」面板 →
   代点「导入零件/装配」→ 文件框填入 零件B.ics 并「打开」→ 面板内提交确定 →
   等面板关闭 → 等外链真的换成新 ics（**最长 120 秒**，这一步实测要 20 秒左右）。
   权威判据只有一个：设计树里出现“外链指向 零件B.ics”的元素；命中后插件会自动把它选回活选择集，
   接着直接点「重命名」就完成对齐。
   钣金件另有两张业务弹窗（「选择用于外部链接的零件或装配」+「链接的配置」），
   插件会先选中未展开的那一项再点确定——不能省，省了会把“整个场景”插进来，
   钣金零件会变成装配体。

6. 「更新工程图链接文件」
   把图纸环境那张「改变链接文件」对话框自动化为“两列改指向 + 一次确定”，
   用来把图纸里的外链从 设计环境A.ics 改指到 零件名.ics。
   前置：在设计环境里选中一个零部件。虚拟件也允许，但必须「设计环境 == 零件名」。
   文件夹判定：外链件用外链文件所在文件夹；虚拟件用设计环境文档所在文件夹。
   零件名.exb 与 零件名.ics 必须在该文件夹里真实存在。
   链路：进 零件名.exb（冷启动会自动焐热图纸环境）→ 经 CRX 派发 CX_DFT_ChangeLinks →
   逐行试探并改写（按**文件名**认行，绝不按目录认行，避免把同一文件夹里别的件一起改掉）→
   点「确定」提交 → 保存并关闭图纸。
   权威判据是 CRX 日志的 `DB.snapshot … +N -M` 增量，不是“命令跑过了”。

7. 「图纸环境预热」（按钮底色 = 状态灯）
   绿 = 本会话已进过图纸环境（CRX 探针在），开 exb 走热路径；
   黄绿 = 本会话预热过，但预热图纸已按计划立即关掉；
   红 = 本会话还没进过图纸环境 —— 此时直接开图纸有崩 dataexchange.dll 的先例。
   点它：用同目录的 caxa3d图纸环境预热.exb 把图纸环境焐热，成功后当场把这张空图纸关掉。
   图纸相关流程（改名、更新链接）在冷启动时会自动先做这一步，失败才回落“请人工开一次图纸”。

8. 「钣金件设计环境设默认」（只对钣金件生效，点击后直接执行、不弹确认框）
   选中钣金件 → 自动执行该件的独立 .ics：
   打开 → 展开 → 展开件名改为“展开+成品件名” → 配置还原默认 → 保存 → 关闭。不涉及工程图。

9. 「钣金件尺寸填写」（只对虚拟钣金件生效）
   选中「文件名.ics---零件名（虚拟）」的钣金件后点它：
   ① 校验：钣金件（类型 20）、非外链、名称不含“展开”、文件名=零件名
   ② 读材料与板厚（板料属性，mm）
   ③ 找展开件「展开<零件名>」→ ④ 读展开件最小包围盒（最大边=长、次大边=宽、
      最小边须等于板厚 ±0.1mm，否则中止且不写属性）
   ⑤ 回填 SC规格=长x宽、SC材料=<材料>板T=<板厚>（写后回读）
   ⑥ 恢复默认配置 → 复核属性 → 保存
   规则文件 caxa3dsheetsizewriteaddfix.txt 与插件同目录。

10. 「工程图标题栏设默认」
   选中零部件（文件夹内有同名 exb）→ 打开 exb → 派发“标题栏-右键-设置3D信息”，
   自动选缺省配置并确定 → 保存并关闭。每步兜底等待不超过 10 秒，超时即判失败，
   不会强行保存或关图。

11. 「手动图号分离」（只分离、不改名）
   名称来源：优先用「新零件名」输入框内容；为空则用原零件名。
   段数与规则不符时弹提示，不做任何修改。与「自动图号分离」开关无关，随时可用。

12. ④ 区工具按钮
   · 零部件重新生成：选中件 Update（钣金件补 Refold/Activate）后刷新场景界面，
     用于“改名已落盘但设计树还显示旧名”。
   · 窗口前置：置顶开关（默认置顶，方便边选零件边看窗口），再点一次解锁。
   · 图号分离规则 / 使用说明：打开同目录的 txt。
   · 刷新连接：重新读取当前活动文档与选中件。
   · 注册CRX / 卸载CRX：登记/撤销图纸环境命令模块（自动请求管理员权限，重启 CAXA 生效）。
   · 保存日志 / 清理日志：导出或清空下方日志区。

四、图号分离规则
------------------------------------------------------------
格式：<规则名>.间隔符"<分隔符>"----"<属性1><分隔符><属性2>..."
  示例  A自制件.间隔符" "----"SC图号 SC名称"        零件名按空格分两段
         B外购件.间隔符"_"----"SC名称_SC规格_SC材料_SC图号"
规则文件与插件同目录，改完重开插件窗口即生效；段数与规则不符时会弹提示，不做任何修改。

五、常见问题
------------------------------------------------------------
  · 提示“CRX 未就绪”：点「注册CRX」（会自动请求管理员权限）→ 重启 CAXA 3D。
  · 「部件重新生成」后设计树还是旧名：确认改名已落盘（回读在日志里），再点一次；
    装配体下较慢，属正常。
  · 提示“未检测到新 ics 文件”：检查 2027 选项里的同名联动开关，或旧图未转存。
  · 工程图没更新 / 一直不关：确认同目录下 exb 文件名与新零件名一致；
    日志若写“图纸『X』现在没开着 —— 不投关闭命令”，说明这张图根本没打开过，
    插件不会去关别的窗口（避免误关设计环境），请人工处理这一张。
  · 「替换零部件」等很久：命令期间 CAXA 会清空选择集，外链真正换好要约 20 秒，
    判据给到 120 秒；期间不要重复点按钮。
  · 「带图独立」被拒：它要求“外链文件名 = 零件名”，替换完没改名时会被有意拒绝 ——
    这时直接点「重命名」对齐即可。
  · 需要排障：界面「保存日志」导出运行日志；详细调用轨迹在
      %TEMP%\caxa3dcodenameextraction_trace.log
    图纸环境轨迹在
      %TEMP%\caxa3dcodenameextraction_crx.log

六、卸载
------------------------------------------------------------
  · 插件：仓库根的 卸载.bat（restore.ps1），只按正则移除本插件自己的条目，
    不影响其他插件共存。
  · CRX：界面点「卸载CRX」，或运行 unregister-crx.ps1。
  · 图纸桥 CRX 需要重编译时（改了 caxa3dcodenameextraction-crx\ 下的 C++）：
    双击插件目录的 重编CRX.bat，再跑仓库根 build.ps1 + 安装.bat。
