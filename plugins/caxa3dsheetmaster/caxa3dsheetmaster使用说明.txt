caxa3dsheetmaster（CAXA 3D 折弯管理大师）使用说明
=====================================================

一、安装
  1) 先完全退出 CAXA 3D（含后台进程）。
  2) 双击「安装.bat」，按提示允许管理员权限。
  3) 脚本会把 caxa3dsheetmaster.dll 复制到 CAXA 3D 各年份版本的 bin 目录，
     并写入 IronCad.Addin.config、IronCad.exe.manifest 与 HKCU 注册项。
  4) 重新启动 CAXA 3D，在「设计环境」功能区的「折弯管理」按钮即可打开界面。

二、使用
  1) 打开含钣金件的装配或零件（.ics 装配 / 钣金零件）。
  2) 点击功能区「折弯管理」。窗口会自动扫描当前设计场景的钣金折弯。
     · 表格一行 = 一个折弯特征；列序为：序号 / 折弯特征名称 / 系统名称 /
       折弯角度 / 板材厚度 / 使用零件的最小折弯半径 / 内半径 /
       使用零件的折弯扣除 / 使用零件K系数 / 折弯系数类型 / 折弯系数数值 /
       新类型 / 新数值 / 修改 / 结果。
       列宽按单元格内容与表头文字自动调整，表头折行时自动加高表头行；
       总宽超出窗口时可拖动下方的水平滚动条。
     · 「使用零件的最小折弯半径」列：内半径等于零件最小折弯半径（板料/零件属性）时显示「是」，
       否则显示「否」；显示「是」时该行内半径不可编辑，显示「否」时可直接在「内半径」格输入新值，
       改完立即写回 CAXA 并回读校验。
     · 「使用零件的折弯扣除」列：只在「折弯系数类型 = 折弯扣除」时才有意义。
       「是」= 该折弯的扣除值等于零件继承值（CAXA 会忽略单独写入的扣除值）；
       「否」= 该折弯用自己的扣除值，可被单独修改；
       「—」= 系数类型不是折弯扣除，不适用（该格不可编辑）。
       这一列可直接在表格里改：改成「是」会把扣除值写回零件继承值；
       改成「否」需要先在「新数值」填一个与零件继承值不同的扣除值。
     · 「使用零件K系数」列：只在「折弯系数类型 = K因子」时才有意义。
       「是」= 该折弯沿用零件 K 因子；「否」= 该折弯用自己的自定义 K 因子；
       「—」= 不是 K 因子类型，不适用（该格不可编辑）。同样可直接在表格里改。
     · 零件名为「展开…」的展开态零件会被自动跳过（规则 28：展开件与折弯件是兄弟节点）。
  3) 统一设置：选「K因子」或「折弯扣除」，填数值，点「统一修改」。
     · K因子：写入每个钣金件的零件级 K 因子，并让所有折弯改用零件 K（勾上「使用零件K系数」）。
     · 折弯扣除：把所有折弯的系数类型改成「折弯扣除」，扣除值统一为你填的 mm。
     · 写入后立即回读校验，并在表格中显示落盘后的真实值。
  4) 单行修改：在「新类型 / 新数值」列选择并输入，点该行「修改」。
     · 单行选「K因子」= 给该折弯写「自定义 K 因子」，只影响这一条折弯。
  5) 「保存图纸」才会落盘（IZDoc.Save，返回 hr=0 才算成功）；
     「重新生成」用于刷新几何，大装配较慢，按提示确认后执行。
  6) 长任务（扫描/统一修改/重新生成）都有进度提示与「停止」按钮；
     停止后不会保存文件，也不会关闭任何图纸。
  7) 「探针」按钮（排查用，只读、不改模型）：把当前场景的钣金件属性、
     每条折弯线的几何/来源元素、全部折弯系数属性导出到
     桌面\caxa3dsheetmaster_probe_<时间>.txt。表格异常时请先点探针，
     把该文件连同 %TEMP%\caxa3dsheetmaster_trace.log 一起发给开发。

三、单位口径
  · CAXA 3D API 长度单位为「米」，界面统一显示为 mm（板厚 0.002 m → 2 mm）。
  · 折弯角度 API 为弧度，界面显示为度。
  · 若某零件板厚换算后明显异常（<0.15mm 或 >20mm），日志会给出警告。

四、常见问题
  · 按钮没出现：确认安装脚本的最后「verification」四项都是 True，然后重启 CAXA。
  · 表格为空：确认打开的是含钣金件的设计场景；点「重新加载」重试。
  · 写入显示「未生效」：说明接口调用后回读值没有变化，请把
    %TEMP%\caxa3dsheetmaster_trace.log 发给开发排查。
  · 插件未起效时先看 %TEMP%\caxa3dsheetmaster_trace.log（每次 CAXA 启动会重写）。

五、卸载
  双击「卸载.bat」，脚本会删除 DLL 并从共享配置/清单中精确摘除本插件条目，
  不会影响其它已安装插件。
